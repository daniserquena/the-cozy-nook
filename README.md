# The Cozy Nook

## Purpose
The Cozy Nook is a front-end furniture store website with a warm earth-tone look. It helps visitors browse furniture categories, learn about the store, and send a message through a sample contact form.

## How to open the website
1. Download or unzip the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser. You can also use the Live Server extension in Visual Studio Code.
4. Keep the `images` folder beside the HTML, CSS, and JavaScript files so the images can load.

## Pages and features
- `index.html` — homepage, furniture categories, featured products, and shopping links.
- `product.html` — product categories with a category filter and sample product details.
- `about.html` — the store story, mission, and showroom information.
- `contact.html` — store contact details and a validated sample message form.
- Add to Cart and Order Now buttons update the cart number in the navigation bar. The count is saved in the browser for this front-end demo.
- Contact form submission displays an on-page confirmation. It does not actually send or store messages.
- The site uses Bootstrap's responsive grid, custom CSS, and JavaScript.
